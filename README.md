# BTC/USDT M15 单画线

TradingView **Pine v5** 指标。在 BTC/USDT 图上自动识别水平支撑 / 阻力，按「被测试的质量」分四档，
每档独立着色与虚实线，按档次分排序后限额输出，右侧打印中文标签。

设计基准周期 **M15**，但任意周期都能运行（参数里的「识别回看根数」按周期自行调整）。

---

## 加载方式

1. TradingView → 打开 BTCUSDT 图表（建议切到 15m）
2. 底部面板 → **Pine 编辑器**
3. 全选删除原有内容 → 粘贴 `BTC_USDT_M15_单画线.pine` 全部内容
4. 点「保存」→ 点「添加到图表」

## 标签体系（4 档 × 2 侧 = 8 类）

| 类别 | 判定条件 | 线型 | 颜色 |
|---|---|---|---|
| **已证实的 阻力 · 供给卖** | 被触及 ≥1 次，且每次都反向走出「有效拒绝」幅度 | 实线 | 红 |
| **变节者 阻力 · 供给卖** | 原支撑被跌破后转为阻力（角色反转） | 虚线 | 红 |
| **弱不牢固的 阻力 · 供给卖** | 被碰过，但没有一次构成有效反转 | 虚线 | 橙 |
| **未经测试的 阻力 · 供给卖** | 摆动高点形成后价格从未回来 | 虚线 | 红 |
| **已证实的 支撑 · 需求买** | 被触及 ≥1 次，且每次都向上走出「有效拒绝」幅度 | 实线 | 绿 |
| **变节者 支撑 · 需求买** | 原阻力被突破后转为支撑（角色反转） | 虚线 | 绿 |
| **弱不牢固的 支撑 · 需求买** | 被碰过，但没有一次构成有效反弹 | 虚线 | 浅绿 |
| **未经测试的 支撑 · 需求买** | 摆动低点形成后价格从未回来 | 虚线 | 绿 |

「测试=N」后缀只出现在「已证实」档，N 是有效拒绝次数。

## 判定逻辑

```
摆动点识别 (ta.pivothigh / ta.pivotlow, 左右各 6 根)
        ↓
逐簇探测：扫过枢轴之后的每根K线，把"连续贴着该位"的K线归为一次触及
        ↓
每一次触及分类：
    超出该位 ≥ 有效穿越%  → 计入穿越次数 (brk)
    否则看后续 24 根内反向走出 ≥ 有效拒绝%  → 计入有效测试次数 (tests)
        ↓
按 (touched, tests, brk) 定档 → 8 类
        ↓
第一轮：每类按档次分排序 + 同类最小间距去重 + 每类限额
第二轮：现价上方 / 下方各自限额
        ↓
画线 + 右侧中文标签
```

**档次分** = `4 × 测试次数 + 本档权重`（权重顺序可在参数里切换）。
测试次数优先于"离现价远近"，所以历史被反复验证的老位不会被近处噪声挤掉。

## 参数

### ① 显示哪些类别
8 个开关，关掉即不画该类。

### ② 识别参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 摆动点 左/右K线数 | 6 / 6 | 左右各 N 根内最高/最低才算摆动点 |
| 识别回看根数 | 900 | 15m × 900 ≈ 9.4 天 |
| 回踩容差 % | 0.40 | 价格走进距该位多少 % 以内即算「触及」 |
| 有效穿越 % | 0.60 | 超出该位这个幅度以上算「被击穿」 |
| 有效拒绝 % | 1.00 | 触及后反向走出这个幅度算一次「有效测试」 |
| 拒绝观察K线数 | 24 | 触及后观察多少根判断是否反转 |
| 独立簇间隔K线数 | 6 | 两次触及相隔少于这么多根算同一次 |
| 贴近现价忽略 % | 0.20 | 离现价太近的摆动点不画（噪声） |

### ③ 数量与排序

| 参数 | 默认 | 说明 |
|---|---|---|
| 每类最多几条 | 3 | 四类 × 两侧，每类先各自限额 |
| 现价上方最多几条 | 6 | |
| 现价下方最多几条 | 4 | |
| 同类最小间距 % | 0.35 | 同侧两条线价位差小于此百分比时只留一条 |
| 排序方式 | 综合 | `综合` = 按档次分；`距离` = 只按离现价远近 |
| 档次顺序 | 测试>变节者>已证实>弱>未测 | 决定本档权重 |

### ④ 手动价位（追加）

```
价格|标签;价格|标签
例：80445|MT5阻力;75609|MT5支撑
```

留空则只用自动识别。手动线用金色实线，与自动识别的线并存。

### ⑤ 颜色与样式
阻力/支撑/弱阻力/弱支撑 四色、线宽、向右延长 K 线数（默认 60 ≈ 15 小时）、是否显示右侧中文标签。

## 两条使用注意

1. **只在最后一根 K 线重算重画**（`barstate.islast`）。历史 K 线上不会出现线，这是刻意设计——避免指标把几百根历史 K 线都画满。
2. **切换周期后要重看一下输出条数**。「识别回看根数」默认 900 是按 15m 调的，切到 5m 相当于只回看 3 天，切到 1H 相当于回看 37 天。按需调整。
